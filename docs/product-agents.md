| Pattern | What it means |
|---|---|
| Approve, then act | The agent drafts an action; a named person approves it in Slack; then the workflow acts and reads the result back |
| Envelope, else approve | Inside a pre-approved envelope set in Config it acts on its own; anything outside asks the named approver |
| Draft for review | Nothing is written, filed or sent; the draft goes to a named reviewer |
